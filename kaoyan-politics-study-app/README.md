# 研政 · 101 主动学习

这是 `kaoyan-politics-study-app` skill 的端到端示例实现。

## 示例用户提示

> 我是二战考生，马原概念辨析薄弱，每天只有 25 分钟。请做一个手机优先的 101 政治学习 App，用原创单选/多选题带我完成答题—错因诊断—速记—立即重测—间隔复习，并能看今日队列和完整模拟卷结构。

## 运行

```bash
python3 -m http.server 4173
```

然后打开 `http://127.0.0.1:4173`。

## 验证题库

```bash
python3 scripts/validate_questions.py data/questions.json
```

## 当前功能

- 今日主动学习队列、到期复习时间线和可配置的每日比例。
- 9 项分类筛选、错题/收藏/到期/易混点快速筛选，以及本轮题目去重。
- 完整客观题学习面：逐项解析、错因诊断、错因对应动作、知识卡、易混对比、记忆秘诀、正式表述、立即巩固题和复习时间。
- 10 分钟原创迷你模考：8 题答题卡、倒计时、严格多选计分、成绩明细和错题回流。
- 材料分析“定位—原理—结合材料—结论”框架训练及自评清单。
- 基于跨日期正确提取的掌握度；同一天重复答对或快速猜对不会直接升级为“已掌握”。
- 时政可信来源手动导入与版本记录；未经核验的来源不会自动生成题目。
- 桌面与 390px 手机排版。

## 内容边界

- 全部示例题为本项目新写，未复制商业题库。
- 同一轮刷题按题目稳定 ID 去重，全部完成后停止，不会自动循环；刷新页面仍保留本轮进度。只有主动开启新一轮或在错题本点击“重做”才允许再次出现。
- 2027 官方大纲未随 skill 附件提供，因此考试结构明确标记为“2026 公开结构基线”。
- 未提供经过核验的时政来源包，因此时政区只提供来源导入入口，不虚构事实。
- 附件缺少 skill 中提到的 `references/`、标准 schema 和 validator；本项目提供了兼容的本地 schema 与验证器。
